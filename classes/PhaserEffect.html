Class PhaserEffect

CacophonyEffect that builds a phaser AudioWorkletNode — a classic MXR/Univibe-style allpass-cascade phase shifter (Smith STAN-M-21; PASP §8.9). Mirrors ReverbEffect: build idempotently loads the worklet module on the supplied context, then constructs the node with the supplied PhaserOptions as parameterData. Honors the cross-context contract (builds against the bus's context, not the host's own).
