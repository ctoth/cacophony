Interface CacophonyLogger

Minimal logging seam used by Cacophony for host-side (main-thread) diagnostic output. Injecting a logger via RuntimeOptions.logger — or silencing all output via RuntimeOptions.quiet — lets embedders (notably Node / headless / CLI hosts) capture or suppress the [cacophony/worklet] chatter without monkey-patching console.
